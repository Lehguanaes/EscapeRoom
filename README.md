# Quem é o Assassino nessa Empresa?

Projeto desenvolvido para a **Feira Tecnológica da Fatec Zona Leste**.

## Sobre o projeto

"Quem é o Assassino nessa Empresa?" é um escape room digital de investigação. A experiência convida o participante a assumir o papel de investigador e resolver um caso por meio de desafios interativos, pistas e análise de evidências.

Ao longo do jogo, o participante precisa organizar uma mensagem, manipular estruturas de dados e cruzar informações para descobrir quem cometeu o crime.

## Objetivo

Apresentar conceitos de **Análise e Desenvolvimento de Sistemas** de forma leve, prática e divertida. O jogo transforma conteúdos técnicos em desafios acessíveis para estudantes e visitantes da feira.

## Desafios do jogo

O escape room possui cinco etapas:

1. **Mensagem fragmentada:** reorganize as palavras para descriptografar uma mensagem.
2. **Cofre de pilha:** utilize os conceitos de `push`, `pop` e `top` para formar uma palavra.
3. **Código da deque:** manipule letras pela frente e pelo fim da estrutura para recuperar um código.
4. **Cruzamento de álibis:** analise os registros e formule uma conclusão provisória.
5. **Evidência final:** conecte todas as pistas para realizar a acusação correta.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `investigacao_assassinato.html` em um navegador.
3. Clique em **Iniciar investigação** e comece a resolver o caso.

Não é necessário instalar dependências ou executar servidor local.
