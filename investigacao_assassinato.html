ANTES DE COMEÇAR

Um informante foi encontrado morto. Ele deixou mensagens, registros de sistema e acessos ao prédio. Sua equipe deve investigar, analisar informações e conectar evidências para descobrir quem cometeu o crime.

Este escape room foi desenvolvido por estudantes de Análise e Desenvolvimento de Sistemas. As pistas usam ideias dessa área, mas foram preparadas para que qualquer pessoa curiosa consiga resolvê-las.

COMO FUNCIONA?

  • O jogo tem 5 etapas, todas neste mesmo computador.
  • Para avançar, resolva o desafio atual.
  • Cada solução desbloqueia a próxima evidência.

ETAPA 2 — O COFRE DE PILHA

O que é uma pilha?
Imagine uma pilha de pratos: tudo acontece pelo topo.
Mas aqui vamos usar uma pilha de letras.
- push coloca uma letra no topo;
- pop retira a letra do topo;
- top confere a letra que está no topo sem removê-la.

O cofre precisa que você revele uma Palavra Secreta para receber uma nova pista. Os comandos foram embaralhados: descubra a ordem que forma a palavra. Depois, use TOP para confirmar a resposta.

ETAPA 3 — O CÓDIGO DA DEQUE

O que é uma deque?
Imagine uma fila com duas entradas: é possível trabalhar tanto pelo começo quanto pelo fim.
Mas aqui vamos usar uma deque de letras.
- addFront coloca uma letra na frente;
- addBack coloca uma letra no fim;
- removeFront retira a primeira letra;
- removeBack retira a última letra.

A etiqueta recuperada informa que a próxima evidência está no BLOCO C. Cada comando trabalha com apenas uma letra e permanece disponível para novas tentativas. Monte o código da frente para o fim e confirme sua resposta.
